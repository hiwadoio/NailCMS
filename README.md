# Салон «Блеск»

Сайт маникюрного салона: услуги, онлайн-запись, отзывы, SEO и админ-панель. Контент в **MySQL**; в `settings/` — подключение к БД и логин админки. **PHP 8.1+**, PDO, CSS-модули, ES-модули без сборщика.

Рассчитан на **виртуальный хостинг**: один PDO на запрос, выборочная загрузка данных, лимиты форм, кэш статики.

---

## Требования

| Компонент | Версия |
| --------- | ------ |
| PHP | 8.1+ |
| MySQL / MariaDB | 8.0+ / 10.3+ |
| Расширения | `pdo_mysql`, `mbstring`, `json`, `session`, `fileinfo` |
| Apache | `mod_rewrite`, `mod_headers`; желательно `mod_expires` |

**Не коммитить:** `settings/db.php`, `settings/admin.php`, `settings/install.lock`, `*.zip`.

---

## Установка

1. Загрузите проект в корень (`public_html`), чтобы открывался `index.php`.
2. Создайте **пустую** базу MySQL.
3. Откройте `https://ваш-домен/install/`.

| Режим | SQL-файл |
| ----- | -------- |
| Пустой сайт | `install/schema-tables.sql` (только таблицы) |
| С тестовыми данными | `database/schema.sql` (таблицы + демо-контент) |

4. Введите MySQL и логин админа → **удалите каталог `install/`** после проверки.

**Ручная установка:** `mysql … < database/schema.sql`, затем `settings/db.example.php` → `db.php`, `admin.example.php` → `admin.php` + `password_hash`.

### Права

```bash
chmod 750 settings lib database install
chmod 640 settings/db.php settings/admin.php
chmod 775 assets/images/services
```

## Что удалять, а что оставлять

| Путь | После установки |
| ---- | ---------------- |
| `install/` | **Удалить** с сервера (мастер больше не нужен) |
| `database/` | **Оставить** в репозитории — `schema.sql` для демо-режима и повторного импорта; по HTTP закрыт `.htaccess` |
| `settings/db.example.php`, `admin.example.php` | **Оставить** — образцы для ручной настройки |
| `lib/`, `includes/`, `admin/`, `api/`, `css/`, `js/`, `assets/` | **Обязательны** для работы сайта |

Каталог `database/` **не лишний**: без него не работает установка «с тестовыми данными» и ручной импорт из README.

## Защита Apache (`.htaccess`)

| Файл | Назначение |
| ---- | ---------- |
| `/.htaccess` | ЧПУ, `Options -Indexes`, блок `lib/`, `settings/`, `database/`, шаблонов; кэш CSS/JS/изображений |
| `lib/.htaccess`, `settings/.htaccess`, `database/.htaccess` | Deny all |
| `includes/.htaccess` | Только `sitemap.php`, `robots.php`, `services.php`, `reviews.php` |
| `includes/content/`, `includes/partials/` | Deny all |
| `api/.htaccess` | Только 4 PHP-эндпоинта форм |
| `admin/.htaccess` | noindex, запрет `/admin/template/` |
| `install/.htaccess` | Только `install.php` и `install.css`; все `.sql` закрыты |
| `assets/images/.htaccess` | Без PHP в каталоге загрузок |

Дублирующих или неиспользуемых `.htaccess` в проекте нет — каждый закрывает свой уровень каталога.

## Безопасность

- PDO prepared statements.
- Админка: `password_hash`, CSRF, lockout, `SameSite=Strict`.
- API: `Origin`/`Referer`, honeypot, капча.
- Загрузка фото: до 3 МБ, `finfo` + `getimagesize`, только `assets/images/services/`.
- Пустые SEO-поля не выводятся в HTML (`setting_filled()`).

## Шаблоны HTML (`includes/`)

PHP-шаблоны публичного сайта. Подключаются через `require` из `index.php` или точек входа `/services`, `/reviews`. Прямой доступ по URL к большинству файлов закрыт `.htaccess` (исключения — см. ниже).

### Корень `includes/`

| Файл | Назначение |
| ---- | ---------- |
| `.htaccess` | Разрешает HTTP только для `sitemap.php`, `robots.php`, `services.php`, `reviews.php`; остальные `.php` — запрет |
| `header.php` | Открывающая часть страницы: `<head>` (meta, Open Graph, Twitter, JSON-LD), шапка с логотипом и навигацией. Учитывает главную и внутренние страницы; пустые SEO-поля не выводятся |
| `footer.php` | Подвал сайта (контакты, Schema.org), модальные окна **отзыва** и **подтверждения записи** с капчей, подключение `js/main.js` |
| `main.php` | Контент **главной**: блок услуг (до 6), форма онлайн-записи, блок отзывов (до 6), кнопки «Посмотреть все», пустые состояния |
| `slider.php` | Промо-слайдер на главной (3 статичных слайда с акциями). Управляется `js/modules/promo-slider.js`; тексты слайдов не из БД |
| `services.php` | Точка входа страницы `/services`: bootstrap → `header` → `page-services` → `footer` |
| `reviews.php` | Точка входа страницы `/reviews`: bootstrap → `header` → `page-reviews` → `footer` |
| `page-services.php` | Разметка страницы «Все услуги»: заголовок, полный список услуг или пустое состояние, ссылка «На главную» |
| `page-reviews.php` | Разметка страницы «Все отзывы»: сводка рейтинга, полный список или пустое состояние, кнопка «Написать отзыв», «На главную» |
| `sitemap.php` | Генерация `sitemap.xml` (главная, `/services`, `/reviews`) |
| `robots.php` | Генерация `robots.txt` (закрытие служебных путей от индексации) |

**Сборка главной** (`index.php`):

```
header.php → <main> → slider.php + main.php → footer.php
```

### `includes/content/`

Фрагменты разметки списков; подключаются из `main.php` и страниц каталога. HTTP-доступ закрыт `.htaccess`.

| Файл | Назначение |
| ---- | ---------- |
| `.htaccess` | Запрет прямого доступа |
| `services-list.php` | Сетка карточек услуг: обходит `$services_list` и для каждой подключает `partials/service-card.php` |
| `reviews-list.php` | Список отзывов: обходит `$reviews_list` и для каждого подключает `partials/review-card.php` |

### `includes/partials/`

Переиспользуемые блоки разметки. HTTP-доступ закрыт `.htaccess`.

| Файл | Назначение |
| ---- | ---------- |
| `.htaccess` | Запрет прямого доступа |
| `service-card.php` | Одна карточка услуги: фото, название, краткий текст, цена, кнопка «Подробнее» (открывает модалку услуги через `data-*` атрибуты) |
| `review-card.php` | Одна карточка отзыва: автор, дата, услуга, звёзды рейтинга, текст |
| `section-more.php` | Блок-ссылка «Посмотреть все услуги» / «Посмотреть все отзывы» с подписью (например, «Всего 12 услуг»). Параметры: `$more_href`, `$more_label`, `$more_meta`, `$more_variant` |
| `section-empty.php` | Пустое состояние, если услуг или отзывов нет. Параметры: `$empty_message`, `$empty_hint`, `$empty_variant` (`services` / `reviews`), опционально кнопка действия |

## API (`api/`)

JSON-эндпоинты для форм на публичном сайте. Вызываются из JavaScript (`fetch`). Каталог открыт по HTTP, но в нём только 4 скрипта.

| Файл | Назначение |
| ---- | ---------- |
| `.htaccess` | Доступ к каталогу; заголовки `noindex`, `nosniff` |
| `booking-captcha.php` | **GET** — выдаёт арифметический вопрос капчи для записи (JSON: `ok`, `question`). Rate limit 40/час |
| `review-captcha.php` | **GET** — капча для формы отзыва (тот же формат) |
| `submit-booking.php` | **POST** — приём заявки на запись: валидация, honeypot, капча, проверка услуги из БД → таблица `bookings` |
| `submit-review.php` | **POST** — приём отзыва на модерацию → таблица `pending_reviews` |

**Защита запросов:** только POST/GET по назначению; проверка `Origin`/`Referer`; honeypot-поле `website`; rate limit 12 отправок форм/час; капча в сессии `blesk_public`.

**Зависимости:** `submit-*.php` подключают `lib/bootstrap.php` (профиль `api_booking` — имена услуг для проверки); капча — только `lib/captcha.php` + `lib/security.php`.

## Админ-панель (`admin/`)

Панель управления по адресу `/admin/`. Контент хранится в MySQL; шаблоны — PHP без отдельного фреймворка.

### Корень `admin/`

| Файл | Назначение |
| ---- | ---------- |
| `.htaccess` | `noindex`; запрет прямого URL `/admin/template/`; заголовки безопасности |
| `index.php` | Точка входа: роутинг `?page=`, проверка авторизации, подключение шаблона в `layout.php` |
| `bootstrap.php` | Обработка всех POST (вход, CRUD, загрузка фото, настройки, заявки); функции `admin_save_*`, `admin_find_*` |
| `css/admin.css` | Стили админки: карточки, таблицы, формы, кнопки, флеш-сообщения |

**Страницы (`?page=`):** `dashboard`, `settings`, `services`, `service-edit`, `reviews`, `review-edit`, `bookings`.

### `admin/template/`

Экраны админки; прямой HTTP-доступ закрыт `.htaccess`.

| Файл | Назначение |
| ---- | ---------- |
| `.htaccess` | Запрет прямого доступа |
| `layout.php` | Общая оболочка: `<head>`, меню разделов, счётчики новых заявок/отзывов на модерации, вывод flash/error, вставка текущего шаблона |
| `login.php` | Форма входа (логин, пароль, CSRF) |
| `dashboard.php` | Главная админки: краткая сводка, ссылки на разделы с счётчиками |
| `settings.php` | Редактирование всех полей `site_settings` (SEO, контакты, бренд) |
| `services.php` | Таблица услуг: фото, название, цена, ссылки изменить/удалить |
| `service-edit.php` | Форма создания/редактирования услуги (тексты, цена, загрузка JPG/PNG/WebP) |
| `reviews.php` | Очередь `pending_reviews` + список опубликованных отзывов; одобрить/отклонить/удалить |
| `review-edit.php` | Ручное добавление или правка отзыва (автор, дата, услуга, оценка, текст) |
| `bookings.php` | Заявки на запись: статусы `new` / `in_progress` / `completed` / `cancelled`, смена статуса, удаление |

**Схема запроса:**

```
index.php → bootstrap.php (POST) → layout.php → template/{page}.php
```

### Что можно делать в админке (по страницам)

Вход: `/admin/` (если не авторизованы — форма логина). После входа доступны разделы в верхнем меню. Все изменения сразу попадают на публичный сайт (данные в MySQL).

| URL | Страница | Что можно сделать |
| --- | -------- | ----------------- |
| `/admin/` | **Главная** (`dashboard`) | Увидеть сводку: сколько новых заявок и отзывов на модерации; перейти в любой раздел; открыть сайт в новой вкладке |
| — | **Вход** (`login`) | Войти по логину и паролю (задаются при установке). После 5 неудачных попыток — блокировка на 15 минут |
| `/admin/?page=settings` | **Настройки сайта** | Изменить всё, что видит посетитель «вокруг» контента: адрес сайта (`site_url`), название салона, город, слоган, телефон, email, meta title/description/keywords, Open Graph и Twitter, Schema.org, цвет темы браузера. Пустые SEO-поля на сайте не выводятся, пока их не заполните |
| `/admin/?page=services` | **Список услуг** | Просмотреть все услуги (фото, название, цена); перейти к редактированию; удалить услугу; кнопка **«Добавить услугу»** |
| `/admin/?page=service-edit` | **Новая услуга** | Создать услугу: название, цена, галочка «от … ₽», картинка (путь или загрузка JPG/PNG/WebP до 3 МБ), краткий текст для карточки, подробный текст для модалки, описание для поисковиков |
| `/admin/?page=service-edit&id=…` | **Редактирование услуги** | То же, что при создании, для существующей услуги |
| `/admin/?page=bookings` | **Заявки на запись** | Просмотреть заявки с формы на сайте (имя, телефон, email, услуга, желаемая дата, комментарий); сменить статус: **Новая** → **В процессе** → **Выполнена** / **Отменена**; удалить заявку. Новые заявки подсвечиваются в меню |
| `/admin/?page=reviews` | **Отзывы** | **На модерации** — отзывы с сайта: одобрить (появятся на сайте) или отклонить. **Опубликованные** — список уже на сайте: редактировать, удалить. Кнопка **«Добавить вручную»**. Средняя оценка и счётчик на главной пересчитываются автоматически |
| `/admin/?page=review-edit` | **Новый отзыв** | Добавить отзыв без модерации: автор, дата, услуга (из списка), оценка 1–5 (шаг 0.5), текст |
| `/admin/?page=review-edit&id=…` | **Редактирование отзыва** | Изменить опубликованный отзыв |

**Общее для всех разделов (кроме входа):**

- Выйти — кнопка **«Выйти»** в меню.
- Сообщения об успехе (зелёные) и ошибках (красные) после сохранения.
- Ссылка **«Сайт»** — открыть публичную главную.

**Типичные сценарии:**

1. **Новая заявка с сайта** → «Записи» → сменить статус, перезвонить клиенту.
2. **Новый отзыв с сайта** → «Отзывы» → блок «На модерации» → «Одобрить» или «Отклонить».
3. **Новая услуга в прайсе** → «Услуги» → «Добавить услугу» → загрузить фото → «Сохранить».
4. **Сменили домен или телефон** → «Настройки» → `site_url`, контакты → «Сохранить настройки».

**Чего нет в админке:** редактирование промо-слайдера на главной (тексты слайдов в `includes/slider.php`, статическая вёрстка).

## PHP-ядро (`lib/`)

Серверная логика сайта и админки. Каталог **закрыт от HTTP** (`.htaccess` → deny all).

| Файл | Назначение |
| ---- | ---------- |
| `.htaccess` | Запрет прямого доступа |
| `bootstrap.php` | Инициализация публичного сайта: настройки из БД, `$services` / `$reviews` по профилю страницы |
| `app-context.php` | `app_load_profile()` — какие данные грузить (главная, API, админка, sitemap…) |
| `install-guard.php` | Редирект на `/install/`, пока нет `install.lock` и настроенной админки |
| `init.php` | PHP-настройки: `display_errors=0`, strict sessions |
| `db.php` | Singleton PDO из `settings/db.php` |
| `data.php` | Работа с MySQL: CRUD услуг, отзывов, заявок, настроек; проверка схемы БД |
| `security.php` | HTTP-заголовки, CSRF API, rate limit, проверка Origin, валидация id и путей файлов |
| `captcha.php` | Генерация и проверка капчи (отдельные ключи сессии для записи и отзыва) |
| `public-session.php` | Сессия `blesk_public` для форм и rate limit |
| `admin-auth.php` | Вход в админку: `password_hash`, CSRF, lockout, сессия `blesk_admin` |
| `helpers.php` | `e()`, `site_url()`, `asset_url()`, даты, Schema.org JSON-LD, лимиты главной |
| `reviews-helpers.php` | Звёзды рейтинга, средняя оценка, подписи «N отзывов» для шаблонов |
| `bookings-helpers.php` | Константы и подписи статусов заявок (`BOOKING_STATUS_*`) |

**Цепочка публичной страницы:**

```
bootstrap.php → install-guard → init → app-context → db → data → helpers
```

## Настройки (`settings/`)

Конфигурация вне git (кроме примеров). Каталог **закрыт от HTTP**.

| Файл | Назначение |
| ---- | ---------- |
| `.htaccess` | Запрет прямого доступа |
| `app.php` | Пути проекта: `ROOT_DIR`, `SETTINGS_DIR` |
| `db.example.php` | Образец подключения MySQL → копировать в `db.php` |
| `db.php` | **Рабочий** конфиг БД: host, database, user, password (не коммитить) |
| `admin.example.php` | Образец логина админки и `password_hash` |
| `admin.php` | **Рабочий** логин и хеш пароля администратора (не коммитить) |
| `install.lock` | Создаётся мастером установки; признак завершённой установки (не коммитить) |

Контент сайта (тексты, услуги, отзывы) хранится **только в MySQL**, не в `settings/`.

## Чеклист после установки

1. Главная, `/services`, `/reviews` — без ошибок.
2. Запись и отзыв с капчей → данные в админке.
3. Вход в `/admin/`, актуальный `site_url` (https).
4. Каталог **`install/` удалён**.
5. Прямой URL `https://домен/database/schema.sql` → **403 Forbidden**.

После смены домена обновите `site_url` в админке → **Настройки**.
